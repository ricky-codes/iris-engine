Prompts

O prompt de sistema que cada ferramenta manda ao modelo. Vem da versão ativa na base de dados (prompt_version) ou, sem versão ativa, do código (src/tools/<ferramenta>.ts). As memórias são acrescentadas no fim, em cada pedido.

Memórias

Instruções curtas guardadas no Postgres e juntas ao prompt em cada pedido. As da org são regras da empresa e prevalecem; as de utilizador são preferências pessoais.

Custos

De onde vem o custo de cada pedido e para onde vai. A IRIS não guarda custos na base de dados: recebe-os do OpenRouter, soma-os por pedido e envia-os ao StepAccess. Os números abaixo são desta instância, desde o arranque.

Configuração

Cada valor tem uma origem. Do mais fraco para o mais forte: código → .env (lido ao arrancar) → base de dados (engine_setting, muda sem reiniciar) → por ferramenta (tool_config).

Base de dados

As tabelas que existem agora no Postgres, lidas do catálogo (/v1/admin/database), com as linhas e as ligações. Nunca mostra o conteúdo das linhas.
